# 📊 ABC Sales Analysis using Microsoft Excel

## 📌 Project Overview

This project is an Excel-based Sales Analysis Dashboard designed to analyze business performance, sales trends, and profitability. It provides a clear overview of sales data through interactive visualizations and reports.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Understand profitability and business trends.
- Present key business insights through visual dashboards.
- Support data-driven business decisions.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Data Analysis
- Data Visualization
- Excel Dashboard
